# Submission package

This folder contains the Hackstreet Boys submission documents and pitch deck.

- `SDC2026_HackstreetBoys_Preliminary.pdf` - completed preliminary proposal
- `SDC2026_HackstreetBoys_TechDeclaration.pdf` - completed technical and tools declaration
- `Stock_Manager_Pitch_Submission.pptx` - pitch deck
- `SDC2026_HackstreetBoys_Replit_POU.pdf` - official Replit proof-of-use template; replace this
  file with the team's completed evidence before the final portal submission

RunPod is not used because the prototype has no GPU workload. The live Replit
prototype is available at https://hackstreetboys-stock.replit.app/stock_manager/
and was verified on 24 October 2026. The final public demo-video URL is still required.
